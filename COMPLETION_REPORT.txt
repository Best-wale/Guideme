================================================================================
                        GETTING STARTED
================================================================================

STEP 1: Setup (5 minutes)
  1. pnpm install
  2. cp .env.example .env.local
  3. Add OpenAI key and AWS credentials to .env.local

STEP 2: Create Database (5 minutes)
  1. Go to AWS Console → DynamoDB
  2. Create 3 tables (or use CLI commands)
  3. Enable TTL on each table

STEP 3: Run Locally (5 minutes)
  Terminal 1: pnpm dev           (backend)
  Terminal 2: pnpm watch:ext     (extension)

STEP 4: Load in Chrome (1 minute)
  1. chrome://extensions/
  2. Enable Developer mode
  3. Load unpacked → .output/chrome-mv3
  4. Visit any website, press Ctrl+Shift+G

STEP 5: Test (5 minutes)
  Go to github.com → Ask "How do I fork a repo?"
  Watch the extension guide you visually!

STEP 6: Deploy (30 minutes)
  1. vercel (deploy backend)
  2. Update API URL in extension
  3. pnpm run build:ext (rebuild)
  4. Test with production API

TOTAL TIME TO LAUNCH: ~1-2 days (including AWS setup & testing)
